# Load the data into Oracle

1. Run `sales_analysis_oracle.sql` to create the table.
2. Open the table in SQL Developer and choose **Import Data**.
3. Select `Sample - Superstore.csv`.
4. Match the columns in the same order as the table.
5. Set Order Date and Ship Date format to `MM/DD/YYYY`.
6. Run the checks and reports in the SQL file.
